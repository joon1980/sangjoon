# 2026_KAIST_AgenticAI_Workshop_iAILab

## 📚 강좌 개요

- **강좌명**: 실제 산업 환경에 적용 가능한 AI 자동화 시스템 설계 및 구현
- **핵심**: 실무 중심 실습으로 AI 기반 자동화 시스템을 직접 구현
- **목표**: 산업 적용 가능한 AI 전략, RAG/LLM/AI Agent 기술 이해 + 실전 설계/구현 역량 확보

---

## 🗓️ 제1일

### 10:00-11:00 (이승철 교수)
#### 생성형 AI 및 LLM 기반 기술의 산업 활용 전략 이해
- 생성형 AI 및 대형 언어모델(LLM) 핵심 개념
- 산업 현장 활용 전략
- 실제 사례로 기술 수준·한계 파악
- 조직 도입 방향성 및 고려사항
- 기업환경 AI 활용 전략 기초 마련

### 11:00-12:00 (이준형 박사)
#### 프롬프트로 코딩한다! Vibe Coding 실전 활용법
- 자연어 프롬프트 기반 코드 생성 개념
- Vibe Coding 실제 활용 방법
- 프롬프트 설계로 개발 생산성 향상
- 반복 작업 자동화 기법
- AI 기반 개발 패러다임 변화 및 실무 적용 역량 강화

### 12:00-13:00 (이승철 교수)
#### RAG 기반 기술 문서 검색 시스템 및 챗봇 구축
- RAG(Retrieval-Augmented Generation) 구조 소개
- 기술 문서 검색 시스템 설계/구축
- 자연어 문서, DB 기반 정보 검색
- 생성형 AI 결합 구조 이해
- 효율 정보 활용 구현 실습

### 14:00-18:00 (이남정 PM)
#### AI 기반 보고서 및 시각화 자동 생성
- 데이터 기반 보고서 자동 생성
- 시각화 자동화 방법
- 다양한 데이터 입력→인사이트 도출→문서/시각 자료 변환
- 실습 중심 반복 보고서 자동화
- 의사결정 지원 역량 강화

#### 진단 보고서 비교 AI Agent 구현
- 여러 진단 보고서 비교·분석 AI Agent 설계/구현
- 문서 간 차이점 및 인사이트 자동 추출
- 비교 분석 자동화 기술 적용
- 복잡 문서 분석 효율적 AI 시스템 방향 제시
